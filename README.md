# HyperStage

以四份 Hyper3D ZIP 模型與八個 FBX 角色建立的 MMD 風格網頁舞台編輯器。使用 Three.js、Vite，所有模型處理都在瀏覽器本機進行。

## 啟動

需要 Node.js 22.12+（本次使用 Node.js 24）。

```sh
npm install
npm run dev
```

開啟終端顯示的本機網址。正式版本：`npm run build`，輸出 `dist/`；`npm run preview` 可預覽。不要直接雙擊 HTML；GLB 載入需要 HTTP 伺服器。

## 功能

- 切換 12 個內建模型，或匯入單一 GLB／FBX。
- 旋轉、平移、縮放鏡頭，正面／側面／俯視快捷鍵。
- 靜態、搖擺、整體旋轉、浮動四種動態。
- 12 秒時間軸，播放／暫停、拖曳定位、速度、循環與空白鍵控制。
- 新增關鍵影格後，移動時間軸並調整朝向／高度／大小，會在該時間新增或更新影格；影格之間使用線性插值。
- 四種舞台配色、燈光強度、網格與自動環繞鏡頭。
- PNG 舞台截圖；JSON 專案匯出與還原，包含內建角色、關鍵影格、鏡頭和場景設定。

## 模型限制

原本四個 ZIP 各含 PBR 和 shaded GLB，沒有骨架或動畫。新增的 drive-download ZIP 含八個 FBX，已解壓至 public/models/fbx，全部具有骨架、蒙皮與內嵌 emissive 貼圖，但動畫僅約 0.033 秒姿勢片段。素材本身不含完整舞蹈；本專案另提供程序式骨架編舞（見下節）。真正的 MMD 骨架舞蹈仍需綁骨、動作重定向，以及 PMX／VMD 相容流程；本版未實作 PMX／VMD 匯入。若匯入 GLB 本身含動畫，會依時間軸播放它的動畫。

自訂 GLB／FBX 目前可檢視和播放，但不會嵌入 JSON 專案，介面會提示先切換內建角色再儲存。原 ZIP 完整保留；`public/models/1..4` 對應依 ZIP 檔名排序的模型。

## 驗證

`npm run build` 已通過。瀏覽器已確認四個 GLB 載入、播放時間推進、關鍵影格建立、配色切換；測試記錄與截圖在 `verification/`。

## 歌詞演出：《最瞎結婚理由》

網頁開啟後直接進入歌詞劇場，按「播放演出」開始。完整保留提供的 33 句歌詞，預設 132 秒，分為序幕、鋒兄求婚、副歌、塗哥中獎、雙對婚禮五幕。每幕都有角色站位、整體搖擺／跳躍、分鏡、名字標籤及愛心／彩紙／婚禮拱門效果。預設選用 FBX 鋒兄、牙妹、小塗、魚妹，右側可從全部 12 個模型更換四個角色的分配，點選歌詞或章節直接定位。取消「分鏡鏡頭」可自行拖曳視角。

預設載入 public/audio/wedding.mp3 與 LRC，含 19.37 秒前奏，依時間戳同步字幕。歌詞微調為「頭獎券」「好幾張」「十桌百桌」「都在笑這兩段緣」。可匯入本機 MP3／WAV 等瀏覽器支援的音檔，使用音訊時鐘帶動演出；字幕按曲長平均分配，不是語音辨識或精確逐句對齊。移除音檔恢復 132 秒。瀏覽器可能要求實際點擊播放按鈕才允許音訊播放。

演出走位仍為整體變換；FBX 預設使用程序式骨架舞蹈，支援雙人牽手與抱抱，尚未實作嘴型。同一角色可分配至多個位置，各自使用獨立骨架。演出分配、音檔與播放狀態只保留在本次頁面中；返回編輯器的 JSON 儲存仍只適用原先的單模型場景。PNG 截圖擷取 3D 畫面，不包含 HTML 歌詞字幕。

`npm test` 驗證歌詞邊界、重定時的章節定位、全曲角色變換穩定性。

## 骨架舞蹈

8 個 FBX 角色現可直接跳舞，歌詞演出預設啟用「骨架舞蹈」，編輯器亦有同名動態按鈕。舞蹈包含踏步律動、交替揮手、斜向指天、胸前合拍、雙手上舉、側步擺臂、胸前收手和鞠躬；並新增抬膝擺臂、前踢推掌、側踏展臂、交叉步揮手、滑步輪臂、點踵轉腕、扭步出拳與後勾腿畫圓，共 16 組動作。各幕安排不同八拍樂句並交叉混合。頭、脊椎、肩、手臂、手腕、大腿、小腿與腳踝皆由骨架驅動。每幀由絕對時間計算，支援暫停、定位、反向拖曳與循環；腳部骨骼最低點用於高度補償。

此為原創程序式編舞，不是原曲動作捕捉或現成 VMD。預設 120 BPM，介面可調 60–200 BPM 與動作幅度；未自動偵測歌曲拍點。未提供精確足部 IK 鎖定或裙襬物理，仍可能有滑步或服裝穿插。原四個無骨架 GLB 保留整體走位。取消骨架舞蹈可回到 FBX 原始姿勢。


## 雙人牽手與抱抱

固定配對：**鋒兄 × 牙妹**、**小塗 × 魚妹**。右側「雙人互動」可選兩對牽手、兩對抱抱、隨劇情或各自跳舞。

隨劇情模式在鋒兄求婚段安排第一對、小塗中獎段安排第二對，最後雙對婚禮一起互動；每段先牽手，8–10 秒漸變為抱抱，段落頭尾淡入淡出。手臂使用雙骨 IK，抱抱時面向伴侶並以雙臂環抱，牽手時調整手掌朝向。暫停及拖曳時間軸均可預覽。需勾選「骨架舞蹈」，無骨架 GLB 不支援接觸動作；此為程序式姿勢，沒有手指抓握或衣物碰撞模擬。

`npm test` 包含配對、劇情切換與 IK 測試。開發頁面 console 執行 `await (await import('/verification/check-couples.js')).checkCouples()` 可驗證四個實際 FBX 的牽手／抱抱目標誤差及反向切換一致性。

## 使用者體驗（UX 重構）

`src/main.js`（編輯器）與 `src/performance.js`（歌詞劇場）已由壓縮單行改寫為可讀的分段程式；共用工具在 `src/ui.js`，新增樣式在 `src/ux.css`。

- **開場卡片**：舞台中央顯示大型「播放演出」按鈕，載入時顯示 4 位角色的實際下載進度；播完（未循環）顯示「再看一次」；載入失敗可一鍵重試。
- **演出控制列**：上一句／下一句、音量與靜音、全螢幕；時間軸下方的分幕區段依實際時長等比例排列，點擊即跳轉。手機直向時播放鍵改為圖示以免擠壓。
- **鍵盤**：Space 播放、←→ ±5 秒、↑↓ 上下句、[ ] 上下幕、Home/End、M 靜音、F 全螢幕、L 循環、C 分鏡鏡頭、Esc 返回編輯器（面板內「鍵盤快捷鍵」有列表）。
- **手機**：播放時保持螢幕常亮；切到背景自動暫停；支援鎖定畫面／耳機媒體鍵（Media Session）。
- **記住偏好**：角色分配、互動模式、骨架舞蹈、BPM、動作幅度、分鏡鏡頭、循環、音量存於本機瀏覽器。
- **歌詞清單**：自動置中目前句；使用者手動捲動時暫停自動捲動 4 秒。字幕依句內進度呈現卡拉 OK 漸層。
- **編輯器**：播放頭、點 ◆ 跳到影格、雙擊刪除；鍵盤 Space、←→ 逐格（Shift 1 秒）、K 新增、Del 刪除、G 網格、R 重設視角、1/2/3 視角；可把 GLB／FBX／專案 JSON 直接拖進舞台；模型載入顯示進度條。

## 發行版打包

- **PC（`hyperstage-<版本>-pc.zip`）**：`npm run build` 後，把 `dist/` 複製為 `HyperStage-<版本>/app/`，再放入 `release/pc/` 的啟動器（Windows `Start-HyperStage.bat` + `serve.ps1`、macOS `start-mac.command` + `serve.py`、`README.txt`）後壓縮。啟動器是支援 HTTP Range（音樂可拖曳定位）的本機伺服器，免安裝。
- **Android（`hyperstage-<版本>-debug.apk`）**：`npx cap sync android`，再於 `android/` 以 JDK 21 執行 `./gradlew assembleDebug`。
