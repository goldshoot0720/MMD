HyperStage — 歌詞劇場（PC 版 · 9 首歌）
==========================================

請先「完整解壓縮」整個 ZIP，再依系統執行：

  Windows：雙擊  Start-HyperStage.bat
           （會開一個黑色視窗並自動打開瀏覽器；關閉視窗即停止）
           若出現「Windows 已保護您的電腦」，按「其他資訊 → 仍要執行」。

  macOS  ：雙擊  start-mac.command
           第一次若被阻擋：按右鍵 → 開啟。需要 python3
           （終端機輸入 xcode-select --install 可安裝）。

  Linux  ：python3 serve.py

請勿直接雙擊 app/index.html —— 瀏覽器不允許從檔案直接載入模型。

建議使用最新版 Chrome 或 Edge。
操作說明：角色載入完成後自動播放（瀏覽器阻擋時請按「播放演出」），右側「選擇歌曲」可換歌；Space 播放／暫停、← → 快轉、F 全螢幕。
